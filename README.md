# 🌸 Menopause Symptom Checker

A beginner-friendly web tool to help women identify possible menopause-related symptoms based on age and health indicators

## 📌 Overview

This project was created to support women's health awareness using simple web technologies. It helps users select their age group and symptoms, and gives a basic suggestion on whether they may be experiencing menopause.

> ⚠️ **Disclaimer:** This is not a diagnostic tool. Please consult a qualified doctor for medical advice.

---

## 💻 Tech Stack

- **HTML** – Structure  
- **CSS** – Styling  
- **JavaScript** – Logic/Interactivity  

---

## 🚀 How to Use

### 👉 Option 1: Run Locally
1. Download or clone this repository
2. Open `index.html` in your browser

### 👉 Option 2: Run Online (Replit)
1. Go to [https://replit.com/](https://replit.com/)
2. Create a new **HTML, CSS, JS** Repl
3. Paste the code into the respective files
4. Click **Run**
